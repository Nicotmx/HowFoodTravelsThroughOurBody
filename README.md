# How Food Travels Through Our Body

## Project Overview

How Food Travels Through Our Body is an educational Android application developed as part of the Multimedia Programming course. The application aims to help children learn about the digestive system through interactive multimedia content, including text, images, audio narration, video, animations, quizzes, and image processing technology.

The application provides an engaging learning experience by allowing users to explore digestive organs, observe food movement through the digestive system, participate in interactive activities, and analyse food images using OpenCV.

---

## Features

### Learn Module

* Introduces the major digestive organs.
* Audio narration for each organ.
* Educational video about the digestive system.

### Organ Explorer

* Interactive exploration of digestive organs.
* Displays organ descriptions and progress tracking.

### Food Journey Animation

* Demonstrates how food travels through the digestive system.
* Includes Start, Pause, Continue, and Reset controls.
* Displays stage descriptions and progress indicators.

### Drag and Drop Challenge

* Users arrange digestive organs in the correct order.
* Provides immediate feedback on answers.

### Digestive Simulator

* Allows users to drag food items to a character.
* Displays digestion information and nutritional content.

### Quiz Module

* Multiple-choice questions related to the digestive system.
* Instant feedback and final score calculation.

### Food Scanner

* Integrates OpenCV image processing.
* Analyses selected food images.
* Displays nutritional information, digestion details, and fun facts.

## Installation

1. Clone or download the repository.
2. Open the project using Android Studio.
3. Allow Gradle synchronization to complete.
4. Connect an Android device or launch an emulator.
5. Run the application.
